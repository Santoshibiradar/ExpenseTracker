\# 💰 Expense Tracker



A simple and user-friendly \*\*Expense Tracker\*\* web application that helps users record, manage, search, and monitor their daily expenses while keeping track of their monthly budget.



\## 📌 About the Project



Managing daily expenses can be difficult when spending is not tracked properly.



The \*\*Expense Tracker\*\* provides a simple dashboard where users can:



\- Add and manage expenses

\- View total spending

\- Count the number of expenses

\- Calculate the average expense

\- Set a monthly budget

\- Track the remaining budget

\- Search expenses

\- Filter expenses by category

\- View recent expenses in an organized table



The project focuses on providing a clean and easy-to-use interface for personal finance management.



\---



\## ✨ Features



\### 📊 Expense Dashboard



The dashboard displays important financial information:



\- \*\*Total Expenses\*\* – Shows the total amount spent.

\- \*\*Number of Expenses\*\* – Shows the number of recorded expenses.

\- \*\*Average Expense\*\* – Calculates the average amount spent per expense.



\### 💵 Monthly Budget



Users can set a monthly spending limit.



The application displays:



\- Monthly budget

\- Amount spent

\- Remaining budget

\- Budget progress



This helps users understand how much money they have left to spend.



\### ➕ Add New Expense



Users can enter the details of a new expense and add it to their expense list.



Typical information includes:



\- Expense name

\- Amount

\- Category

\- Date



\### 📋 Recent Expenses



All recorded expenses are displayed in an organized table.



The table contains:



| Expense | Amount | Category | Date | Action |

|---------|--------|----------|------|--------|



\### 🔍 Search Expenses



Users can search for a particular expense using the search box.



\### 🗂️ Category Filter



Expenses can be filtered according to their category using the category dropdown.



This makes it easier to understand where money is being spent.
